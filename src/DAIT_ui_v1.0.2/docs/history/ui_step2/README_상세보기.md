# 4단계: 뉴스 상세보기

서버가 실행 중이면 `Ctrl+C`로 종료한 뒤 다시 실행하세요.

```powershell
py ui_step2\app.py
```

브라우저에서 http://127.0.0.1:8000 을 열고 기사 제목을 클릭합니다. 현재 목록 위에 열리는 카드 팝업에서 제목, 출처, 한국 시간(KST) 기준 발행 시각, 카테고리, RSS 기사 설명과 출처 링크 목록을 볼 수 있습니다. 현재 DB에는 기사당 원문 주소가 하나씩 저장되어 목록에 한 개가 표시됩니다. 목록의 주소와 원문 보기 버튼은 같은 기사로 연결되며 새 탭에서 열립니다. 기사 설명이 비어 있으면 그 사실을 안내합니다. 닫기 버튼 또는 Esc 키로 팝업을 닫을 수 있습니다.

## 확인할 내용

1. 비로그인 목록에서 기사 하나를 선택하고 팝업의 제목, 출처, 발행 시각, 카테고리가 선택한 기사와 같은지 확인합니다.
2. 원문 기사 보기 버튼으로 해당 언론사의 기사가 열리는지 확인합니다. 원문 사이트의 접속 제한에 따라 열리지 않을 수 있습니다.
3. 팝업을 닫은 후 기존 목록과 위치가 유지되는지 확인합니다. user1, user2, user3 각각의 추천 기사에서도 팝업을 열고 닫아 사용자 선택 상태가 유지되는지 확인합니다.
4. http://127.0.0.1:8000/article/not-found 로 접근하면 기사를 찾을 수 없다는 404 오류가 표시되는지 확인합니다.

설명은 수집 당시 RSS가 제공한 텍스트로, 기사 전문이나 AI 3줄 요약이 아닙니다. 해외 기사의 한국어 제목과 요약 생성·표시 방법은 `../ui_step3/README_해외한국어.md`를 참고하세요. 본문·번역문 표시 여부는 언론사 이용 조건 확인이 필요합니다. 카테고리는 키워드로 추정한 값입니다.

현재 팝업은 저장된 AI 요약도 별도 영역에 표시합니다. 요약 연결 기준과 테스트 방법은 `../ui_step3/README_요약연결.md`를 참고하세요.
