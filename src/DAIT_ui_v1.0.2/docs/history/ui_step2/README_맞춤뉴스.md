# 3단계: 테스트 사용자별 맞춤 뉴스

2단계 서버를 종료한 뒤 다시 실행하세요.

```powershell
py ui_step2\app.py
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 상단의 `user1`, `user2`, `user3` 버튼으로 사용자를 전환하고 `로그아웃`을 누르면 비로그인 화면으로 돌아옵니다. 이 버튼은 화면 테스트용 계정 선택이며 비밀번호나 실제 사용자 인증을 구현한 것은 아닙니다. 브라우저 쿠키에 선택한 테스트 계정만 저장합니다.

| 테스트 사용자 | 관심사 |
|---|---|
| user1 | 인공지능 |
| user2 | 보안, 클라우드 |
| user3 | 반도체 |

**임시 테스트 기준:** 관심사 중 하나 이상이 기사 카테고리와 일치하면 추천하며, 최신순 최대 10개를 보여줍니다. 일치 기사가 부족하면 다른 카테고리 기사로 채우지 않고 일치하는 기사만 표시합니다. 이는 확정된 추천 정책이 아닙니다. 카테고리는 수집 당시 키워드로 추정한 값이라 실제 기사 주제와 다를 수 있습니다.

## 확인 순서

1. 비로그인 상태에서 최신 기사 10개와 순서를 확인합니다.
2. user1, user2, user3을 차례로 선택해 표시된 사용자, 관심사와 기사 카테고리를 확인합니다. 기사가 여러 카테고리를 가진 경우 그중 하나만 일치해도 추천됩니다.
3. 각 사용자를 직접 전환한 뒤 이전 사용자의 목록이 남지 않는지, 새로고침해도 선택된 사용자가 유지되는지 확인합니다. 두 사용자의 관심사에 모두 해당하는 기사는 양쪽에 나타날 수 있습니다.
4. 로그아웃한 뒤 최초의 비로그인 최신 기사 10개와 순서가 다시 나타나는지 확인합니다.

기사 제목을 클릭하면 목록 위에 상세 팝업이 열립니다. 팝업 테스트는 `README_상세보기.md`를 참고하세요. 종료하려면 서버 터미널에서 `Ctrl+C`를 누르세요.
