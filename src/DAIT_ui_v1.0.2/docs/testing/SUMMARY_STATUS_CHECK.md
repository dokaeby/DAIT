# 자동 요약 상태 표시 직접 확인

FastAPI 서버를 재시작하고 브라우저에서 Ctrl+F5를 누릅니다. Ollama와 서버를 실행한 상태에서 새 기사를 수집합니다.

1. 요약 대기 중 → 생성 중 → 생성 완료로 카드 표시가 바뀌는지 확인합니다. 처리 속도에 따라 중간 상태는 짧게 보일 수 있습니다.
2. 미완료 기사 팝업을 연 채 기다립니다. 버튼 없이 상태·요약이 갱신되고 같은 카드의 문장도 반영되는지 확인합니다.
3. 대기·생성·자동 재시도 중에는 생성 버튼이 없어야 합니다. 국내 최종 실패 기사에만 '요약 다시 시도'가 보여야 합니다.
4. Ollama 중지 후 실패가 발생하면 이전 연결 오류만 표시하는 대신 재시도 대기/남은 시간/최종 종료를 구분하는지 확인합니다. 중지 테스트는 필요할 때만 수행합니다.
5. 재시도 종료 후 Ollama를 복구하고 버튼을 누릅니다. 대기 상태로 바뀌고 결과가 자동 갱신되어야 합니다. 현재 처리 중인 기사가 끝나야 실행될 수 있습니다.
6. 생성 중 팝업을 닫고 다른 기사를 열었을 때 이전 기사의 응답이 새 팝업을 덮어쓰지 않는지 확인합니다.
7. 검색·카테고리·계정 전환 후에도 해당 목록과 상태가 유지되는지 확인합니다.

이번 변경은 표시 상태를 정리한 단계이며, 실제 테스트는 사용자 확인을 기다립니다.
