# 설정 안내

실행 설정의 기준 파일은 ../src/dait/core/config.py입니다. 현재 DB 파일명·모델명·화면 경로를 유지합니다. 사용자별 비밀번호나 토큰을 이 폴더에 저장하지 않습니다.

개발 설치는 프로젝트 루트에서 python -m pip install -e . --no-deps를 사용합니다. 기본 프로젝트 루트는 소스 경로로 결정됩니다. 다른 배포 위치의 데이터를 명시적으로 사용해야 할 때만 DAIT_PROJECT_ROOT 환경변수로 기존 data·frontend가 있는 루트를 지정합니다. 일반 개발 실행에서는 설정할 필요가 없습니다.

.env 자동 로드, Redis/PostgreSQL 전환, release/debug 보안 정책은 이번 경로 이동에 새로 도입하지 않았습니다. 고정 모델명을 다른 모델로 바꾸는 작업도 별도의 호환 검토가 필요합니다.
