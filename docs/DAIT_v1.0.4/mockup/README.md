# DAIT 화면 목업

| 항목 | 내용 |
|---|---|
| 버전 | 1.0.4.1 |
| 기준 | `DAIT_화면설계서_v1.0.4.pptx` |
| 화면 | 메인 뉴스 목록, 설정 |
| 제외 | 별도 상세보기 화면, 설정 알림·노출 메뉴(1.0.4.1 제거), API·데이터 저장 |
| 확인 | `index.html`과 `settings.html`을 브라우저에서 연다. |

## 폴더 구성

| 경로 | 화면·역할 |
|---|---|
| `index.html` | 검색·필터·랭킹 카드가 있는 메인 뉴스 목록 |
| `settings.html` | 예약·관심 조건·닉네임·계정 정책 설정 (노출·알림 섹션 제거 — 1.0.4.1) |
| `mockup.css` | 공통 화면 스타일과 반응형 규칙 |
| `mockup.js` | 정적 메인 화면의 카드 표시 |
| `render-evidence.json` | 데스크톱·모바일 화면 확인 기록 |

목업은 화면 구성을 검토하기 위한 정적 산출물이다. 검색, 저장 및 API 연동은 포함하지 않는다.
