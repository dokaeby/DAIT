## 화면별 목적

| 화면 | 사용자가 먼저 확인하는 정보 | 주요 시각 요소 | 반응형 변화 |
|---|---|---|---|
| 메인 | 뉴스 제목, 출처, 3줄 요약, 처리 상태 | 좌측 탐색, 통합 검색, 랭킹 카드 | 모바일에서 좌측 탐색을 하단 탭으로 전환하고 카드를 세로 배치 |
| 뉴스 상세 | 원본 정보, 요약, 번역, 관련 뉴스 | 기사 헤더, 3줄 번호 요약, 원본 정보 패널 | 모바일에서 본문·사이드 패널을 한 열로 전환 |
| 설정 | 예약, 관심 키워드, 노출 수, 알림, 정책 | 설정 구역 메뉴, 입력·토글 예상 상태 | 모바일에서 설정 메뉴를 가로 스크롤하고 입력을 한 열로 전환 |

## 디자인 기준

- 톤: 차분하고 스캔하기 쉬운 기술 뉴스 데스크
- 주요 색상: 흰색 표면, 푸른 강조, 녹색 성공, 주황색 부분 상태
- 정보 우선순위: 제목 → 출처·시각 → 3줄 요약 → 처리 상태 → 행동
- 데스크톱 기준: 1440px 안팎의 넓은 목록 화면
- 모바일 기준: 390px 안팎의 한 열 카드와 하단 탐색
- 접근성 고려: 의미 있는 제목 구조, 버튼 이름, 보이는 포커스, 색상 외 상태 텍스트

## 주의

이 폴더는 화면 구성 검토용이다. 입력, 검색, 정렬, 토글, 저장, 원문 열기와 링크 복사는
구현되어 있지 않다. 제품 코드로 사용하려면 상세설계서에 따라 API, 상태 관리, 검증, 인증·인가와
오류 처리를 별도로 구현해야 한다.
