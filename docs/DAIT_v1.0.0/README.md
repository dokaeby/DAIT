4. 첨부 UI 시안과 이전 기획 문서

## 1.0.0 핵심 결정

- 반응형 웹과 FastAPI JSON API로 구현한다. PyQt6 데스크톱 앱은 구현하지 않는다.
- 운영 DB는 Supabase PostgreSQL, 로컬·테스트 DB는 SQLite, 마이그레이션은 Alembic이다.
- Redis는 캐시, 작업 큐, 속도 제한, 분산 잠금과 임시 상태에만 사용한다.
- MVP는 AI 단일 카테고리, 이메일·비밀번호 인증, 수집·번역·3줄 요약, 목록·검색·상세다.
- 소셜 로그인, 2차 인증, 비밀번호 변경, 예약·개인화, 웹·메일 알림은 다음 단계다.
- 밝은 화이트 대시보드를 시각 기준으로 채택하되 MVP에서 동작하지 않는 메뉴는 노출하지 않는다.
- 원문 전체를 재배포하지 않고 출처·원문 링크·정제된 메타데이터와 생성 결과만 제공한다.

## 변경 규칙

- 기능·API·데이터 구조를 바꾸면 네 문서의 같은 기능 ID를 함께 갱신한다.
- 되돌리기 어려운 결정은 `docs/decisions.md`에 이유와 영향 범위를 기록한다.
- 미결 사항을 구현자가 임의로 확정하지 않는다. 로드맵의 결정 게이트를 통과시킨다.
