# 8단계: 해외 기사 한국어 제목·3줄 요약

기존 해외 기사 중 최신 최대 2개를 대상으로 한국어 제목과 RSS 기반 3줄 요약을 생성합니다. 제목·RSS 설명을 입력으로 사용하며, 전문 수집이나 본문 번역은 수행하지 않습니다. 기사 원본 DB는 읽기만 합니다.

## 실행

가상환경이 활성화된 CMD에서 DAIT_ui 폴더를 기준으로 실행하세요. 먼저 대상 원문과 기사 ID를 확인합니다. 이 명령은 Ollama를 호출하거나 결과 파일을 만들지 않습니다.

```cmd
python ui_step3\translate_foreign.py --list
```

Ollama와 qwen3:4b 모델이 준비되어 있다면 생성합니다.

```cmd
python ui_step3\translate_foreign.py
python ui_step3\translate_foreign.py --status
```

한 기사만 확인하려면 `--count 1`, 대기 시간을 늘리려면 `--timeout 900`을 추가하세요. 같은 입력·모델의 정상 결과는 재사용하며, 정보 부족으로 제목만 번역된 결과도 재사용합니다. 다시 생성하려면 `--force`를 추가합니다. 미생성·실패·입력 변경·형식 오류·모델 변경은 재처리합니다. 연결 장애나 Ctrl+C로 중단해도 저장을 완료한 기사는 남습니다.

## 저장과 표시

- `ui_step3/foreign_translations.db`: 원문 제목·설명, 한국어 제목·요약, 원문 URL, 모델, 입력 해시, 생성 상태와 오류를 실행별로 저장합니다.
- `ui_step3/foreign_report_실행ID.txt`: 원문과 한국어 결과를 비교하는 보고서입니다.
- 원문 DB와 국내 요약 DB의 내용은 수정하지 않습니다.

생성 후 실행 중인 화면 서버를 종료하고 다시 실행합니다.

```cmd
python ui_step2\app.py
```

http://127.0.0.1:8000 에서 해외 기사에 한국어 제목이 표시되는지 확인하세요. 팝업에는 한국어 제목과 요약, 원래 제목, 원문 RSS 설명, 출처 링크를 표시합니다. 원문 RSS 설명은 번역문이 아니며 비교를 위해 그대로 표시합니다. 화면을 열 때는 저장된 결과만 조회하므로 Ollama를 켜 둘 필요가 없습니다.

핵심 정보가 부족하면 제목만 번역하고 3줄 요약은 정보 부족으로 안내합니다. 현재 해외 RSS 설명은 뉴스레터 안내 위주이거나 한 문장뿐이므로 이 상태가 나올 수 있습니다. 미생성·실패·내용 변경·형식 오류일 때는 원문 제목으로 표시하고 해당 이유를 팝업에서 안내합니다. 가장 나중에 저장된 결과를 사용하며 생성 결과를 자동으로 검토 완료 처리하지 않습니다.

## 테스트

1. 보고서와 팝업의 기사 제목·요약·원문 링크가 일치하는지 확인합니다.
2. 인명, 기업명, 수치, 불확실한 표현이 유지되는지 원문과 비교합니다. 세 줄을 채우려고 입력에 없는 사실을 추가하면 안 됩니다.
3. 국내·해외 기사를 번갈아 열어 이전 원문 제목이나 요약이 남지 않는지 확인합니다.
4. 사용자 전환과 로그아웃 후에도 기사 ID에 맞는 결과가 표시되는지 확인합니다.
5. 목록에 없는 해외 기사는 `--list` 출력의 상세 주소로 직접 확인할 수 있습니다.

저장·목록·HTTP 연결 자동 점검은 임시 DB를 사용합니다.

```cmd
python -m unittest discover -s ui_step2 -p test_foreign.py
```

자동 점검은 실제 AI 번역 품질이나 브라우저 팝업 조작을 검증하지 않습니다.
