# Step 5 · 화면설계서 적용

기준: `DAIT_화면설계서_v1.0.3_목업반영_수정.pptx`의 메인, 상세보기, 반응형 화면.
참조 목업: `C:/DAIT/docs/1차기획서수정/mockup/`의 HTML/CSS. 공통 디자인 토큰은 `design.css`에 복사했습니다.

## 실행

프로젝트 루트 `DAIT_ui`에서 기존 서버 진입점을 그대로 사용합니다.

```powershell
.\.venv\Scripts\python.exe ui_step2\app.py
```

기존 서버를 먼저 종료하고 다시 실행한 뒤 http://127.0.0.1:8000/ 에서 새로고침합니다.

## 연결한 기능

- 비로그인 메인과 사용자별 맞춤 메인: 좌측 탐색, 파란 강조색, 기사 정보·요약·행동을 나눈 카드.
- 실제 DB 카테고리 필터, 통합 검색, 의미 유사도 점수, 검색 관련도/최신순 정렬.
- 검색이 없으면 최신순, 검색에서는 혼합 검색 상위 10건을 표시합니다. 최신순 선택은 혼합 검색 상위 결과 안에서 발행일로 정렬합니다.
- 로그인 버튼과 아이디·비밀번호 팝업. user1/user2/user3의 테스트 비밀번호는 1234입니다.
- 기사 제목 또는 상세 보기 클릭 시 상세 팝업. 원문 열기는 별도 새 탭입니다.
- 상세 팝업과 직접 기사 URL의 원본 정보·AI 요약·실제 상태 표시, 원문 링크 복사와 성공/실패 안내.
- 820px 이하에서 모바일 한 열 카드와 하단 탐색, 1100px 이하에서 상세 보조 패널 이동, 430px 이하에서 행동 버튼을 세로로 배치합니다.

목업의 예시 기사, 검증 완료·출처 지연 문구, 관련 기사와 전체 번역 문단을 실제 데이터인 것처럼 사용하지 않습니다. 요약이 없거나 실패하면 현재 상태를 보여줍니다. 생성된 요약은 현재 검토 전 상태로 표시합니다.

설정·알림·저장한 뉴스는 후속 단계입니다. 설정 버튼은 예정 상태로 표시합니다. 해외 기사 전문 번역과 관련 뉴스 추천은 아직 구현되지 않았습니다. 외부 요약 API 연동도 보류 상태입니다.

## 직접 확인할 순서

1. 비로그인 메인: 새 디자인, 실제 기사와 저장된 요약, 미생성 상태가 맞는지 확인합니다.
2. 로그인 팝업: 잘못된 비밀번호, 정상 로그인, 닫기와 Esc를 확인합니다. 비로그인에서 로그인하면 검색어가 지워져야 합니다.
3. user1/2/3 추천 목록, 계정 전환, 로그아웃을 확인합니다.
4. 검색어 입력·삭제·초기화, 카테고리 변경, 의미 유사도 표시와 정렬을 확인합니다. 카테고리와 관심사 범위가 모두 적용되어야 합니다.
5. 제목과 상세 보기로 팝업을 열고 원문 링크, 링크 복사, 다른 기사 연속 열기를 확인합니다.
6. 원문 열기가 상세 팝업을 열지 않고 출처를 새 탭으로 여는지 확인합니다.
7. 기사 제목을 Ctrl+클릭해 직접 상세 페이지의 디자인과 링크 복사를 확인합니다.
8. 브라우저 폭을 820px, 430px 이하로 줄여 카드·버튼·로그인과 상세 팝업의 가독성을 확인합니다.

이번 적용 후 서버·브라우저 및 자동 테스트는 사용자가 직접 수행하기로 했습니다. 실행 검증을 완료한 것으로 기록하지 않습니다.
