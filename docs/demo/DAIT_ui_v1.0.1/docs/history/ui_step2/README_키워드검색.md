# 9단계: 키워드 검색

화면 서버를 종료하고 가상환경 터미널에서 다시 실행하세요.

```cmd
python ui_step2\app.py
```

http://127.0.0.1:8000 의 검색창에서 검색어를 입력합니다. 기사 제목, 원문 RSS 설명, 저장된 해외 기사 한국어 번역 제목을 대상으로 검색합니다. 번역이 없는 기사는 원문 제목과 설명으로만 검색합니다. 검색 시 AI 모델을 호출하지 않습니다.

검색창 값이 바뀌는 input 이벤트마다 즉시 요청해 전체 화면 이동 없이 목록을 갱신합니다. 한글 조합 중에도 변경된 입력으로 검색하며, 모두 지우거나 검색 초기화를 누르면 기본 목록을 요청합니다. 검색 버튼과 Enter 키로도 현재 입력을 다시 검색할 수 있습니다. 이전 검색 요청은 취소하고 최신 입력의 응답만 반영합니다. 결과 표시까지는 서버 응답 시간이 걸릴 수 있습니다.

## 이번 단계의 테스트 기준

- 비로그인: 전체 기사에서 검색 후 최신순 최대 10개를 표시합니다.
- 로그인: 사용자 관심사 중 하나 이상과 일치하는 기사에서 검색 후 최신순 최대 10개를 표시합니다. 관심사에 없는 검색 결과는 채워 넣지 않습니다. 이는 검색과 추천을 함께 확인하기 위한 임시 기준입니다.
- 여러 단어는 공백으로 구분하며 모두 포함되어야 합니다. 영어 대소문자는 구분하지 않습니다. `%`, `_`는 문자 그대로 검색합니다. 유의어·오타·의미 기반 검색은 지원하지 않습니다.
- 검색어가 없거나 공백뿐이면 기존 최신/추천 목록입니다. 검색 초기화는 현재 로그인 상태를 유지합니다.
- 계정을 바꾸면 검색어를 유지해 새 사용자의 관심사로 다시 조회합니다. 로그아웃은 검색어를 비우고 비로그인 최신 기사 10개로 돌아갑니다.
- 검색 결과의 상세 팝업을 닫으면 검색어와 결과 목록이 유지됩니다.

제목이나 RSS 설명의 일부 문자열 일치를 기준으로 합니다. 예를 들어 AI를 입력하면 더 긴 영어 단어에 포함된 ai도 일치할 수 있습니다. AI 요약문과 카테고리 이름 자체는 검색 대상이 아닙니다.

## 확인할 내용

1. 비로그인 상태에서 `TSMC`나 `반도체`를 검색하고 기사 제목·설명에 검색어가 있는지 확인합니다. 최신 10개 밖에 있던 기사도 대상입니다.
2. 존재하지 않는 검색어를 입력해 빈 결과 안내를 확인합니다.
3. `user1 → user2 → user3`으로 바꾸며 검색어는 유지되고 각 관심사 조건이 적용되는지 확인합니다.
4. 검색 결과에서 상세 팝업을 열고 닫아 검색 상태가 유지되는지 확인합니다.
5. 검색 초기화 후 추천 목록, 로그아웃 후 비로그인 최신 목록이 복원되는지 확인합니다.
6. 해외 한국어 제목이 생성된 경우 해당 제목의 한국어 단어로 검색해 연결되는지 확인합니다.
7. `반도체 → 반도 → 반 → 빈칸` 순서로 지워 각 문자열에 포함 일치하는 기사로 자동 갱신되는지 확인합니다. `반도`는 `반도체`라는 단어에도 포함되므로 반도체 기사도 계속 나올 수 있습니다.
8. 빠르게 입력·삭제한 뒤 마지막 검색어와 결과가 일치하는지, 갱신된 목록에서도 상세 팝업이 열리는지 확인합니다.

이 단계에서 키워드 검색 동작을 확인한 뒤, 이후 임베딩 검색과 같은 검색어로 결과를 비교할 수 있습니다.

임시 DB를 사용하는 검색 로직·HTTP 자동 점검:

```cmd
python -m unittest discover -s ui_step2 -p test_search.py
```

Node.js가 설치되어 있다면 실시간 입력·삭제, 이전 응답 무시, 한글 조합 이벤트를 브라우저 없이 점검할 수도 있습니다.

```cmd
node ui_step2\test_live_search.cjs
```
