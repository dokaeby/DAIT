# 메인 통합 검색

메인 검색창에 입력하면 키워드 결과를 먼저 표시하고, 검색어 입력이 잠시 멈추면 키워드와 의미 유사도를 결합한 결과로 갱신합니다. 코사인 유사도는 -1~1이며 정확도나 확률이 아닙니다. 로그인 사용자의 검색 범위는 기존 관심사 조건을 따릅니다.

처음 사용하기 전에 프로젝트 폴더에서 패키지를 설치합니다. 설치와 최초 모델 다운로드에는 인터넷과 저장 공간이 필요합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r ui_step4\requirements.txt
.\.venv\Scripts\python.exe ui_step2\app.py
```

브라우저에서 http://127.0.0.1:8000/ 을 열고 검색합니다. 첫 검색 시 `intfloat/multilingual-e5-small` 모델을 CPU에 불러오고 기사 색인을 준비하므로 오래 걸릴 수 있습니다. 기존 유효 색인은 재사용하고 변경된 기사만 갱신합니다. 이전 BGE-M3 색인은 그대로 보존하며 이 모델의 색인을 별도로 만듭니다. 설치, 다운로드 또는 색인에 실패하면 검색창 아래 오류를 표시하며 키워드 결과는 유지합니다. 검색 중 검색어를 바꾸면 기존 작업 완료 후 최신 검색어를 처리합니다.

혼합 검색은 키워드 후보와 의미 유사도 상위 20개 후보를 RRF로 결합해 최대 10개를 표시합니다. E5 모델의 점수 분포에 맞는 임계값은 아직 검증되지 않아 고정 임계값은 적용하지 않습니다. 관련성이 낮은 기사도 나타날 수 있으므로 실제 검색어로 검토해야 합니다. 유사도 점수 자체가 결합 순위나 확률은 아닙니다. 별도 `/search-lab` 화면은 더 이상 제공하지 않으며 관련 기존 파일은 보존합니다.

AI 요약의 외부 API 연동은 아직 구현하지 않았습니다. 서버를 켤 때 기존 로컬 요약 일괄 작업을 자동 시작하지 않습니다.
