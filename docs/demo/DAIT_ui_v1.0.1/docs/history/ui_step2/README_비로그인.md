# 2단계: 비로그인 최신 뉴스 화면

이 단계에서는 1단계 DB에서 카테고리 조건 없이 발행 시각이 가장 최근인 기사 10개를 조회합니다. 날짜는 한국 시간(KST)으로 표시합니다. 기사가 10개 미만이면 있는 기사만 표시합니다. 기사 제목과 카테고리는 수집된 원문 및 키워드 태그 그대로이며 번역이나 AI 요약은 적용하지 않습니다.

프로젝트 폴더의 VS Code 터미널에서 실행하세요. Python 3 외에 설치할 패키지는 없습니다.

```powershell
py ui_step2\app.py
```

브라우저에서 http://127.0.0.1:8000 에 접속합니다. 종료할 때는 실행 중인 터미널에서 `Ctrl+C`를 누르세요. 8000번 포트를 사용 중이라는 오류가 나면 기존 프로세스를 종료한 후 다시 실행하세요.

## 확인할 내용

1. `비로그인`과 기사 10개가 보이는지 확인합니다.
2. 다른 카테고리의 기사도 최신순으로 섞여 나오는지 확인합니다. 실제 수집 데이터에 따라 최신 10개의 카테고리가 같을 수도 있습니다.
3. `py ui_step1\check_news.py`의 최신 기사 10개와 제목과 순서를 비교합니다. 점검 코드의 날짜는 UTC이며 화면은 한국 시간입니다.
4. 브라우저 폭을 줄여도 제목이 잘 보이는지 확인합니다.

DB가 없거나 읽을 수 없으면 화면 대신 오류가 표시됩니다. `ui_step1/real_articles.db`가 있는지와 1단계 점검 결과를 확인하세요. 로그인, 로그아웃, 기사 클릭 및 상세 화면은 이후 단계에서 구현합니다.
