# DAIT 결정 기록

## 2026-11-04: 문서 기준선 1.0.0

- 결정: FastAPI와 JavaScript 반응형 웹을 구현 기준으로 사용하고 PyQt6 데스크톱 앱은 제외한다.
- 이유: 통합 기획서의 확정 스택과 `docs/AI-config/AGENTS.md`의 기술 범위를 일치시킨다.
- 영향: `docs/v1.0.0/02_전체설계서.md`의 실행·배포 구조.

## 2026-11-04: MVP 범위

- 결정: AI 단일 카테고리, 이메일·비밀번호 인증, 수집·번역·3줄 요약, 목록·검색·상세를
  단계 1로 고정한다.
- 이유: `AGENTS.md`의 개발 단계가 소셜 로그인·개인화·알림보다 MVP 완성을 우선한다.
- 영향: 소셜 로그인과 FR-SET-01~03은 단계 2, 카테고리 확장은 단계 3으로 이동한다.

## 2026-11-04: 화면 기준

- 결정: 첨부된 밝은 화이트 대시보드를 반응형 UI 기준으로 채택한다.
- 이유: 데스크톱과 모바일의 정보 구조가 함께 제시되어 있고 핵심 뉴스 탐색 흐름과 일치한다.
- 영향: MVP에서 동작하지 않는 카테고리·관심·저장·알림 메뉴는 노출하지 않는다.

## 2026-11-04: MVP 랭킹

- 결정: `품질 검증 통과 > 발행 시각 > 출처 우선순위 > 안정적인 ID` 순서를 사용한다.
- 이유: 조회수·언급량처럼 확보되지 않은 지표를 만들지 않고 결정적 결과를 제공한다.
- 영향: 고급 개인화와 외부 지표 기반 랭킹은 단계 3에서 재검토한다.

## 2026-11-04: 작업 처리

- 결정: Redis 큐를 읽는 작은 Python worker로 시작하고 별도 작업 프레임워크를 도입하지 않는다.
- 이유: 현재 기능에 필요한 최소 구조이며 미사용 추상화와 새 의존성을 피한다.
- 영향: 처리량 또는 운영 복잡도가 실제로 증가할 때 측정 결과를 근거로 재검토한다.
